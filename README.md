# ActiveSec

ActiveSec - это проект по анализу и защите систем безопасности, включающий в себя клиентскую часть, драйвер и машинное обучение для анализа данных.

## Описание

Проект ActiveSec представляет собой комплексное решение для анализа безопасности систем. Он включает в себя:
- Клиентскую часть для взаимодействия с пользователем
- Драйвер для низкоуровневого мониторинга системы
- Модели машинного обучения для анализа поведенческих паттернов

## Структура проекта

```
ActiveSec/
├── AS-NET/           # Модели машинного обучения
│   ├── models/       # PyTorch модели
│   └── train/        # Скрипты для обучения
├── Client/           # Клиентская часть
└── Driver/           # Драйвер безопасности
```

## Требования

- Python 3.7+
- PyTorch
- Дополнительные зависимости перечислены в соответствующих файлах проекта

## Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <URL_репозитория>
   ```

2. Установите зависимости:
   ```bash
   # Для Python компонентов
   pip install -r requirements.txt
   ```

## Использование

Для запуска модели машинного обучения:

```python
from AS-NET.models.main_model import create_model

model = create_model()
```
